# Adjustments — missed, moved, and failed sessions

Plans break mid-week. These rules repair the remaining days without breaking `planning-rules.md`. Apply them in order; the first rule that resolves the conflict wins.

## Scoring a completed session

| Outcome | Definition | Effect on progression |
|---|---|---|
| **Completed** | ≥ 95 % of target power or pace on every work rep, RPE within +1 of expected | counts toward "push" |
| **Partial** | all reps done but 1–2 reps below 95 %, or RPE +2 | counts as "hold" |
| **Failed** | a rep below 90 %, or reps cut by more than a quarter | counts as "step down" row |
| **Abandoned** | stopped for fatigue, pain, or illness | step down; check readiness before the next key session |
| **Missed** | not started | neither; see below |
| **Over-cooked** | easy day ridden or run above 75 % FTP / Z3, or reps done > 5 % above target | counts as a hard day for spacing; note it, do not reward it |

Reps done well above target usually mean the threshold is set too low. Two over-target sessions in a row → schedule a benchmark (`testing-and-zones.md`).

## Stopping a session early (cue in the workout description)

- Power or pace on two consecutive reps drops more than 5 % below target at full effort → do one more rep at the lower value, then cool down.
- Heart rate fails to rise on the first two HI reps, or is 10+ bpm above normal for the effort → stop the intervals and ride or run easy. Both signal deep fatigue or illness.
- Any sharp or gait-changing pain → stop immediately.

## Missed key session

1. **Can it move forward one or two days without breaking rules 1–6?** Move it and turn the day it lands on into the easy day it displaces.
2. **Otherwise, can it replace a lower-priority key session later in the week?** Keep the session that matters most for the objective and phase (HI in Build, race-specific in Peak, threshold-type in Base). Drop the other.
3. **Otherwise drop it.** Never stack it next to another hard day, never double up two sessions in one day, and never carry it into the next week.
4. If two key sessions in two weeks were missed, the next week repeats the current step (rule 13 in `planning-rules.md`).

## Missed easy or long session

- Missed Z2: let it go. Do not add the time to the next day beyond +30 min.
- Missed long ride or long run: move it to the next free day only if the day after that is easy. Otherwise extend the next easy session by up to 30 % and keep the long day for next week at the same length, not longer.

## Short on time

Cut in this order: Z2 filler → long-day length → cool-down to 5 min → number of reps (keep intensity). A 45-min version of any key session keeps the warm-up and the first half of the work reps. Never trade a session down by "doing it harder and shorter".

## Extra session added by the athlete (race, hard group ride)

Count it as a hard day. Re-run rules 1–3 for the rest of the week and downgrade the nearest key session to Z2 if any rule fails.

## Travel, weather, and indoor swaps

- Outdoor key session moved indoors: same % FTP, indoor FTP if the rider has one (often 3–5 % lower).
- Treadmill run: set 1 % incline to approximate outdoor effort; pace targets as normal.
- No equipment while travelling: swap bike intervals for run or bodyweight circuits at matching RPE only if the athlete runs regularly. Otherwise easy activity and a rest-day count.

## Reporting changes

Every adjustment is written in the schedule notes in one sentence: what moved, why, and which rule forced it.
